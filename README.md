## Project overview

A collection of two architectural floor-plan drawings created in AutoCAD. The previews make it easy to compare the layouts, while the DWG files let you inspect the drafting work more closely.

| At a glance | What it means |
| --- | --- |
| **2 drawings** | Two separate floor-plan studies |
| **DWG files** | Editable drawings in the project folders |
| **Millimeters** | The documented drawing unit |

## Read the space before the file

Look at room arrangement, circulation, and how the drawing communicates each space. Then open the corresponding DWG for a closer review. These are drafting studies; the README does not present them as approved construction documents.
